# Pictures of the Bundle's pages

What each page is built to look like: the Bundle 0.4.2 (`f11e4f9`, Release) in Playnite on the win11-e2e VM, 1920x1080, taken on 15 November 2026 by the theme repository's `e2e/run.sh port-reference` (its branch `e2e/port-reference-pictures`).

- On this machine: `~/projects/xbox-series-theme/artifacts/e2e/port-reference-20261115-192720/`.
- On GitHub: the `reports` branch, under `m3-reference/`. They show other companies' marks and game art, so they are not on `main`, and that branch goes before the repository is public.
- Older sets in the theme repository's `artifacts/e2e/` dated 10 November show Bundle 0.2.0 and are not to be compared against ([home.md](home.md) lists what changed since).

The library is the theme's test seed plus twelve installed games, so Games scrolls. The Bundle has no Groups page: [filters.md](filters.md) section 6 builds it from the controls in 32, 35, 36, 23 and 13.

## What the pictures show that the source does not say

- **13, text entry over Full library:** the count and the nav still read the whole tab's count while the grid is narrowed; no tab is lit while a name filters; the caption overlaps the first row of tiles. These are the Bundle's own behaviour.
- **22, the details page:** the seed's game has no description, so only the cover and one art card show. A Description and an Info card need a seeded description to be pictured.
- **Not pictured:** Home's Groups and a background with art at this version; the Guide at this version. They are taken with M2's run (#43).
